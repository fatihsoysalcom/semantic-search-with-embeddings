# Semantic Search with Embeddings

This Python example demonstrates a basic form of semantic search using TF-IDF to represent text. It shows how to find documents semantically related to a query, going beyond simple keyword matching.

## Language

`python`

## How to Run

Save the code as `semantic_search.py` and run it from your terminal using: `python semantic_search.py`
